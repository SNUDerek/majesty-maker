# assets info

all art is super-placeholder right now. just enough to get some flavor.

## backgrounds

1920x1080 webp. one for each main 'screen'.

`background_waystation` and `background_capital` are temporary copies (of the pilgrimage background and title page) to be overwritten with proper placeholders.

## fonts

exported to woff2 for web export.

for normal text, use IM FELL DW Pica.

for headings, use rotunda.

## items

all items are from the dungeon crawl 32 x 32 tiles supplemental pack, released as CC0:

https://opengameart.org/content/dungeon-crawl-32x32-tiles-supplemental

items have been renamed to suit this game.

gold directory has coin stacks of various numbers.

the icon_xxx pictures are meant to represent the estates:

bellatores (sword)
oratores (book)
laboratores (hammer)

## misc

includes title page (1920x1080), a parchment background (1600x1080), and zodiac symbols (905x720).

the zodiac symbols are arranged in three rows of four:

aquarius, pisces, aries, taurus

gemini, cancer, leo, virgo

libra, scorpio, sagittarius, capricorn

### misc/intro_panels

intro narration story panels (1024x768).

should be used for a link to the past style intro, following the text document.

### misc/moon_phases

transparent pngs of the moon phases (256x256).

https://opengameart.org/content/2-moon-phases-sets

## portraits

one 360x720 3/4 shot of the princess

then headshot profile pics of princess, tutors, and some miscellaneous figures (360x540), all facing right.

right now, no transparent versions except for main princess body shot.

`portrait_princess_right` is a temporary copy of `portrait_damsel_right`.

## ui

ui elments, in sprite, spritesheet, and vector formats. CC0 free kenny.nl pack.

it's made for 9-slice layouts.

importantly, it supports red, blue, green, and yellow bars.
